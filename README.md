# Retail Sales EDA

## Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to understand sales, profit, customers, products, and regional performance.

## Objective

- Explore and understand the retail sales dataset
- Handle missing and duplicate data
- Analyze sales and profit
- Identify top-performing products and categories
- Analyze customer segments
- Analyze regional sales performance
- Find relationships and patterns in the data
- Create meaningful visualizations

## Dataset

The dataset contains retail sales information including:

- Order Date
- Category
- Sub-Category
- Product Name
- Sales
- Quantity
- Profit
- Discount
- Customer Name
- Segment
- Region
- State
- City

## EDA Performed

### Data Analysis
- Dataset structure and dimensions
- Data types
- Missing values
- Duplicate records
- Descriptive statistics

### Sales Analysis
- Sales by category
- Sales by sub-category
- Sales trends
- Top products

### Profit Analysis
- Profit by category
- Profit by sub-category
- Sales vs profit
- Discount vs profit

### Customer Analysis
- Sales by customer segment
- Profit by customer segment

### Regional Analysis
- Sales by region
- Sales by state
- Sales by city

## Visualizations

The project includes:

- Bar charts
- Line charts
- Distribution plots
- Sales and profit comparisons
- Category and sub-category analysis
- Customer segment analysis
- Regional analysis
- Correlation analysis
